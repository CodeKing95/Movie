# 🎬 Movie and Series Search Engine
This is a Movie and Series Search Engine web application in which it would allow the user to search for movies and explore detailed information such as it's ratings, release dates and plot summaries.
This project also demonstrate the use of API integration, dynamic search functionality, and responsive UI design.

# 🚀 Features
- Search for movies and series by title.
- View detailed movie inforatioms.
- Displaying movie and series ratings, release year and plot summary.
- Real-time search resulsts powered by an external movie and series API.

# 🛠️ Technologies
- Frontend: HTML, CSS & JavaScript.
- Framework: React.
- API: Movie Series Database API.


# 🎯 Purpose of the Project
This main purpose of this project is to:
- Practice working with APIs.
- Implementing search and filtering functionality.
- Improvement of frontend UI skills.
- Developing a real-world application using JavaScript, React and APIs.
